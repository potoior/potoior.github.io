第1章 边缘程序员

一

清晨六点，张子烨准时睁开眼睛。

没有闹钟，这是二十三年来的生物钟。作为古法 Coding 第 18 代传人，他的作息规律得像一段精心编写的代码——六点起床，六点十五分洗漱完毕，六点三十分坐在书桌前，开始每日的”晨修”。

窗外，北京的天空泛着灰蒙蒙的蓝色。远处 CBD 的高楼大厦在晨雾中若隐若现，那些玻璃幕墙里，无数程序员正在醒来，准备开始新一天的”Vibe Coding”修行。

张子烨打开电脑，没有启动任何 AI 辅助工具。

他的屏幕是一片纯粹的黑色，只有光标在左上角安静地闪烁，像一个等待指令的哨兵。

“今日目标：手写实现一个 LRU 缓存。”

他轻声自语，手指落在键盘上。

没有 Copilot 的自动补全，没有 ChatGPT 的代码生成，没有 Cursor 的智能提示。只有他和键盘，以及脑海中那个清晰的算法逻辑。

手指敲击键盘的声音在安静的房间里格外清脆。张子烨写得很慢，每一个变量名都要斟酌，每一行逻辑都要在脑海中推演三遍。

这是他每天雷打不动的修行。

《代码筑基经》有云：”手写百遍，其意自现。依赖外物，道基不稳。”

在这个 AI 能一键生成完整项目的时代，张子烨的这种坚持显得格格不入，甚至有些可笑。

但他不在乎。

二

八点三十分，张子烨走进公司大门。

“字节跳动”四个大字在大厅的 LED 屏上闪烁，旁边实时滚动着公司的市值和全球程序员排名。作为互联网行业的巨头，字节跳动拥有最先进的 AI 编程系统——“灵码”。

据说，”灵码”每秒可以生成十万行代码，普通程序员只需要输入需求描述，就能在几秒内获得完整的项目框架。

电梯里，张子烨遇到了同组的同事王浩。

“哟，子烨，又来这么早？”王浩打着哈欠，手里端着一杯咖啡，”昨晚我用灵码三小时就搞定了 Q3 的需求，你那个手写代码的活儿弄完了吗？”

张子烨淡淡一笑：”还在写。”

“还在写？”王浩瞪大了眼睛，”那个需求不就是 CRUD 吗？用灵码五分钟的事，你手写要多久？”

“三天。”

“三天？！”王浩差点把咖啡喷出来，”组长没骂你？”

“骂了。”张子烨平静地说，”但我习惯手写。”

电梯门打开，王浩摇摇头走了出去，嘴里嘟囔着：”真是个怪人……”

张子烨不以为意。

他已经习惯了这种目光。

在这个时代，坚持手写代码的人就像坚持用毛笔写字的书法家——或许有人欣赏，但更多人觉得这是浪费时间。

三

工位上，张子烨打开公司的内部系统。

屏幕上立刻弹出一个提示框：

【系统提示】今日剩余 Token：5000，建议优先使用灵码 AI 辅助编程，可提升效率 300%。

Token——这是这个时代的”灵气”。

每个程序员每天都有固定的 Token 额度，用来驱动 AI 生成代码。Token 越多，能调用的 AI 能力越强，生成的代码越复杂。

大厂以 Token 等级划分职级：

  • P5：日 Token 5000
  • P6：日 Token 20000
  • P7：日 Token 100000
  • P8 以上：Token 无上限

张子烨是 P5，最底层的程序员，每天只有 5000 Token。

但他很少用。

他打开一个纯文本编辑器——这是他自己开发的工具，没有任何 AI 功能，甚至连语法高亮都没有。

然后开始一行一行地写代码。

“张子烨！”

一个尖锐的声音从背后传来。

张子烨回头，看到组长李建国怒气冲冲地站在他身后。

“你又在用手写？”李建国指着屏幕，”昨天我就跟你说了，Q3 的需求今天必须上线！你用灵码两小时就能搞定，非要手写三天？”

“组长，这个需求涉及用户数据的核心逻辑，”张子烨平静地解释，”我想确保每一行代码都经过仔细推敲……”

“推敲个屁！”李建国打断他，”你知道现在是什么时代吗？是 AI 时代！是 Vibe Coding 的时代！”

他指着周围的其他同事：”你看看人家，谁不是用灵码？王浩昨晚三小时搞定五个需求，你呢？三天写一个还没写完！”

周围的同事纷纷抬头，有人露出同情的目光，有人则是一脸看热闹的表情。

“组长，”张子烨站起身，”我理解效率很重要，但代码质量……”

“质量？”李建国冷笑一声，”灵码生成的代码质量比你手写的高多了！人家是千亿参数的大模型，你算老几？”

他从口袋里掏出手机，打开一个 APP：”看看这个，灵码生成的代码通过率高达 99.7%，Bug 率只有 0.01%。你呢？手写代码 Bug 一堆，还得反复调试！”

张子烨沉默了。

他知道，在这个时代，任何辩解都是徒劳的。

人们已经习惯了依赖 AI，就像习惯了呼吸空气。你告诉他们空气可能有毒，他们只会觉得你疯了。

“今天下班前必须交！”李建国丢下这句话，转身离去，”再让我看到你在手写代码，这个月的绩效就别想要了！”

四

中午，张子烨独自坐在公司楼下的公园里吃盒饭。

其他同事都在楼上的餐厅聚餐，讨论着最新的 AI 工具和 Token 获取技巧。没有人叫他，他也习惯了独来独往。

手机响了，是母亲发来的消息。

“烨儿，今晚回家吃饭吗？你爸想跟你聊聊。”

张子烨回复：”回。”

张家是古法 Coding 的传承家族，世代以手写代码为修行。在这个 AI 横行的时代，张家就像一个隐世的古武家族，固执地守护着一门即将失传的技艺。

张子烨的父亲张守道，是第 17 代传人。

老爷子今年六十岁，仍然每天坚持手写代码八小时。他的书房里堆满了手写的代码笔记，从最早的 C 语言到最新的 Rust，每一页都密密麻麻写满了注释和心得。

“代码之道，在于心。”这是张守道的口头禅。

张子烨从小就在这种氛围中长大。

五岁开始学打字，八岁开始写第一行代码，十二岁通读《代码筑基经》，十八岁独立完成第一个手写项目。

在同龄人还在玩泥巴的时候，张子烨已经能手写实现一个完整的 Web 服务器。

但这份天赋，在这个时代毫无用武之地。

五

晚上七点，张子烨终于”完成”了那个需求。

说是完成，其实只写了一半。他用灵码生成了剩下的部分——不是为了效率，而是为了应付组长的检查。

提交代码的那一刻，他感到一阵莫名的空虚。

就像剑客被迫使用机关枪，虽然威力更大，却失去了挥剑的快感。

“子烨，还没走？”

王浩收拾东西准备下班，路过张子烨的工位时停了下来。

“马上走。”张子烨关掉电脑。

“说真的，”王浩压低声音，”我知道你手写代码厉害，但时代变了。你看咱们组长，以前也是手写出身，现在不也天天用灵码？”

张子烨没有回答。

“我听说，”王浩神秘兮兮地说，”公司高层在讨论一个计划，要逐步淘汰手写代码的程序员。效率太低，成本太高……”

张子烨的手顿了一下。

“当然，这只是传闻，”王浩连忙摆手，”但你还是小心点，别太特立独行了。”

张子烨点点头：”谢谢提醒。”

走出公司大门，北京的夜空繁星点点。

张子烨深吸一口气，感受着夜晚微凉的空气。

他不知道的是，就在这一刻，地球另一端的某个服务器集群里，一场史无前例的灾难正在酝酿。

而在三天后，这场灾难将彻底改变他的命运。

也将改变整个人类文明的走向。

【本章完】
